Monthly schedule: target day of the month for each step

Run targets are the last day of each state’s window in the archived Monthly Data Refresh Documentation (IL 10th–15th, GA 11th–20th, MA 15th–20th); GA’s source data step starts its window on the 11th. DC is still TBD there, so it uses the default. The other steps have no documented dates yet and use placeholder defaults. A state’s column overrides the default; leave it blank to use the default. Risk & Audit steps use the same targets as the matching standard steps. Only editors of this dashboard can save changes.
